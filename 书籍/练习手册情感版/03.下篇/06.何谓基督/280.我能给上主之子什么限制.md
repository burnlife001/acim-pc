# 练习280 我能给上主之子什么限制？

  W-280.1. 凡是上主创造的无限生命，必是自由的，
2. 我可以为祂打造一座监狱，但那只可能发生于幻境内，而非真相中，
3. 没有一个上主圣念离开得了祂的天心，
4. 也没有一个圣念会受到任何限制，
5. 上主的圣念必然永远无瑕可指。
6. 天父既愿圣子享有无限的生命，且如自己一般充满了爱与自由，我还能加给祂什么限制？

  W-280.2. 今天，让我向祢的圣子致敬；唯有如此，我才可能找到祢的道路，
2. 天父，我再也不愿限制祢创造的这无限的爱子了，
3. 我向祂致敬，等于是对祢的致敬，如此，我才可能拥有祢的一切。

七. 何谓圣灵？

  W-pII.7.1. 圣灵是幻相与真相之间的中介，
2. 祂必须在实相与梦境的鸿沟之上架起桥梁，为此，祂赐给所有向祂祈求真理的人一种知见，借着上主赐祂的恩典，将知见导向真知，
3. 一切梦境都会经过祂这座桥梁，进入真理之境，然后销融于真知的光明中，
4. 世上所有的形色音声从此销声匿迹，
5. 知见里的形相世界，一经宽恕，便宁静地告终了。

  W-pII.7.2. 圣灵的课程是为了帮我们结束人生的梦境，
2. 你必须先把形相世界里的恐怖见证解读成爱的见证，
3. 若能彻底做到这一点，你便已完成了"学习"在真理内的唯一目的，
4. "学习"在圣灵的指引下，达到了祂预定的结果后，便能进一步超越自己，让位给永恒的真理。

  W-pII.7.3. 你若知道天父多么渴望你能认清自己的清白无罪，就绝不会充耳不闻圣灵的请求的；祂有意撤换你所造的可怕意象与梦境，你岂能拒而不受祂的礼物？
2. 圣灵非常清楚你为了追逐那不可能完成的目标所设计的种种花招，
3. 只要你把这一切交托给祂，祂就会把这些花招驱逐出境，使你的心灵得以安返它真正的家园。

  W-pII.7.4. 圣灵从上主安置祂的真知之境呼唤着你，让宽恕在你的梦中找到安息之地，恢复你清明的神智及心灵的平安，
2. 若非宽恕，你必会继续饱受梦魇的恐吓，
3. 天父圣爱的记忆也无法返回你的心中，让你看到梦境已经结束了。

  W-pII.7.5. 接受天父的礼物吧！
2. 它是圣爱对圣爱的呼唤，但求恢复自己的本来面目，
3. 圣灵是祂赐给自己爱子的礼物，祂才可能体验到天堂的安宁。
4. 上主一心只愿圆满你的生命，你岂能拒绝这份圆满祂生命的任务？
