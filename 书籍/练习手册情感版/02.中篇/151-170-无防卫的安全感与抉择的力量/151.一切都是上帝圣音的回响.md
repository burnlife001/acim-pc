# 练习151 一切都是上帝圣音的回响

没有人能依据部分证据做出评判，这并不是评判，这只是一种基于无知和怀疑的意见，他表面上的确定，只不过是他所要隐藏的不确定的伪装。
他需要无理性的防卫，因为他就是无理性的，而他的防卫看似牢固，令人信服，并且毫无疑惑，因为所有怀疑都隐藏在表面之下。

你看上去并不怀疑你所看到的世界，你并不会真的去质疑你的肉眼向你展现的一切，你也不会问你为什么会相信他。
即使你早就认识到，你的感官确实会骗你，
更奇怪的是，当你停下来想一想，尽管他们一直在频繁的提供错误的见证，你却依然相信他们所提供的每一个细枝末节。
为什么你会如此含蓄的信任他们呢？除了是因为潜在的怀疑之外，你还会为了什么，而要用表明确定来隐藏怀疑呢？

你怎么能做出评判呢？你的评判是基于你的感官提供给你的证据，但是没有比这更大错特错的证据了。
但你还能怎样评判你所看到的世界呢？你把可怜的信心交给你的眼睛和耳朵向你提交的一切，你认为你的手指触及的是真实存在，并且握住了真相，
这就是你所理解的觉知，认为他比永恒的圣音所见证的一切还要真实。
难道这会是评判吗？反复要求你不要评判，并不是因为你无权评判，你无法评判。
你只能相信自我的评判，而他们全都是错的，
他小心的指引你的感官，以证明你是多么软弱，多么无助和害怕，对正义的惩罚是多么不安，对罪是多么绝望，的有罪让你显得多么可恶，
他会告诉你，他所谈论的并会保卫的这个人就是你自己，你顽固的坚信，确实是如此，但是你还是留有隐藏的怀疑。
他向你所展现的真实，却连他自己也不相信，他所定罪的正是他自己，他正是在他自己之中看到了有罪，他在你内在看到的正是他自己的绝望。

不要聆听他的声音，他提供给你的见证并不是真的，他们只是为了证明，他的罪恶是你自己的，并确定的谈论他们所不知道的一切。
你对他们的信心是盲目的，因为你不愿怀疑他们，尽管他们的主人无法完全压制这种怀疑，
你相信，怀疑他的奴仆，就是怀疑你自己。

但是你必须明白，怀疑他们的证据会为认识你自己扫清道路，并只让上帝的圣音作为神圣评判者来判定什么才值得你相信。
他不会告诉你，你的兄弟应当按你的眼睛所看到的他的样子被评判，应当按他的嘴对你的耳朵说的话，或你的手指所触摸到的样子被评判，他会忽略这些对上帝之子无谓而错误的见证。

他只会认出上帝心爱的圣子，而在他所看到的圣子的神圣光明中，自我所有关于你知所是的梦境，都会在他所注视的辉煌面前消失。
让他成为你之所是的神圣评判者，因为他拥有没有丝毫疑惑的确定性，因为他所给予的神圣确定性是如此伟大，疑惑在他面前会变得毫无意义。

基督不可能对他自己感到疑惑，上帝的圣音只会荣耀他，并因他的完美和永远清白无罪而欢欣，他所评判的人只会嘲笑有罪。
如今，不愿再玩罪的玩具，在基督神圣的欢颜面前，他也不会去注视身体的见证，
他就是这样评判你的，那就接受他对你之所是的圣言，
因为他会为你的美丽创造，以及上帝的神圣心智做见证，而他的神圣思想创造了你的真实存在，他了解圣父和圣子的荣耀，
身体对于他能有什么意义呢？他能听到自我什么样的耳语呢？有什么能使他相信你的罪是真的呢？

让他也成为这个世界上看似发生在你身上的每一件事的神圣评判者吧，
他的功课会让你能在幻觉和真相的鸿沟之间架起桥梁，他会移除你对痛苦、灾难、不幸和缺失的所有信念，
他会赐予你圣见，让你能看穿这些无情的外表，并能注视他们之中基督的和蔼容颜。

你将不再怀疑，上帝深爱着你，并且只有好事才会发生在你身上，
因为他会评判所发生的一切，并教导他们所包含的唯一功课。
他会选择他们之中代表真相的元素，而不去理会那些只反映无谓梦境的方面，
而他会以他唯一而全然统一和确定的参考框架来重新诠释你所看到的一切，发生的一切，每一个处境，以及以任何方式看似与你有关的每一件事。
而你会看到仇恨之上的爱，变化之中的很长，最之中的纯洁，以及天堂对世界的祝福。

这就是你的复活，因为你的生命并不是你所看到的任何东西的一部分，他超越了身体和世界，超越了对非神圣性的所有见证，他在神圣的一切之中，他们像他自己一样神圣。
他的圣音会通过每一个人和每一件事告诉你你的神圣本性和你的神圣创造者，而他们是合一的，
因此，你会在所有事物中看到基督的圣容，并在所有事物中只听见圣音的回响。

今天，除了在练习开始时，我们与上帝一起度过的时间之外，我们将不用言语来进行练习，
我们缓慢的复诵这一思想来开始练习，然后我们观察自己的想法，默默的向他请求，他能看到你想法中真相的元素。

让他评估在你心智中浮现的每一个想法，并移除梦境的元素，让他们还原为不与上帝神圣意愿相矛盾的纯净观念。
把你的想法交给他，他就会把他们作为奇迹再交还给你，这些奇迹会喜悦的宣告，上帝愿他的圣子完整而幸福，而这正是对他永恒圣爱的证明。

当每一个想法都这样得以转化时，他们就会从看到其中真相的神圣心智那里获得疗愈的力量，
不再被错误加入的一切所欺骗，幻想的所有线索都消失了，而留下来的一切统一为一个完美的神圣思想，他会把他的完美带到每一个地方，

在你醒来后，花15分钟时间来这样练习，
在你临睡前，再这样愉快的花15分钟时间。
当你所有的想法都被净化之后，你的神职就开始了，这样你就学会去教导上帝之子有关他神圣性的神圣功课。
当你听到上帝的圣音，荣耀上帝之子时，没有人会不聆听，每一个人都会与你共享，他已在你心智中重新诠释过的思想。

这就是你的复活节，因此，你将雪白的百合花的礼物置于世界之上，以取代对罪和死亡的见证，
经由你的改变，世界就得到了救赎，并欣然摆脱了有罪。
现在他已让我们重获清明神志，我们怀着欣喜和感恩，振作起我们复活的心智，

我们要在每一个小时忆起他，而他就是拯救和解脱。
当我们表达感激时，世界就与我们结合在一起，并欣然接受我们的神圣思想，他们已得到天堂的改正和净化。
现在我们的神职终于开始了，将这个真相中没有任何幻觉的喜讯传遍整个世界，上帝的平安就经由我们而属于每一个人。
